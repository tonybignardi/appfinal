# AppFinal - IFMS Campus Coxim

Aplicativo Flutter de informações do IFMS Campus Coxim, com uma tela inicial em TabView para visualizar professores, disciplinas e estudantes.

## Funcionalidades

- Tela inicial com abas para:
  - Professores
  - Disciplinas
  - Estudantes
- Listagem em estilo cards com ícones e informações resumidas
- Tema visual com cores do IFMS em verde e vermelho
- Gradiente elegante para uma aparência mais moderna

## Tecnologias

- Flutter
- Dart

## Como executar

1. Entre na pasta do projeto
2. Execute:

```bash
flutter pub get
flutter run
```

## Objetivo

Servir como base para apresentação de informações acadêmicas do campus, com visual institucional e layout amigável para usuários.
